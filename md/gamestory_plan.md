# 《赌局陷阱》剧情设计与实施计划

## 一、需求分析

### 1.1 现有项目结构
- **项目类型**：Python Tkinter 互动文字冒险游戏
- **主题**：校园反诈教育
- **现有剧情**："林舒学姐"网恋诈骗（5个结局）

### 1.2 用户需求
用户提供了《咸师反诈迷雾：赌局陷阱》的剧情梳理文档，需要将其整合为游戏可执行的剧情脚本。

**剧情核心要素**：
| 要素 | 内容 |
|------|------|
| 主角 | 大三学生小夏（高帅善良、家境普通、常年兼职） |
| 诱骗者 | 同班同学老蛋 |
| 劝导者 | 同学小林 |
| 主题 | 网络赌博诈骗 |
| 结局数量 | 2个（深渊难爬/理性救赎） |

---

## 二、剧情设计方案

### 2.1 剧情结构（五幕式）

```
【起】第一幕：兼职偶遇（50秒）
    ↓
【承】第二幕：小利诱惑（70秒）
    ↓
【转】第三幕：陷阱收紧（60秒）
    ↓
【合】第四幕：悬崖抉择（30秒）→ 分叉
    ├─→ 结局A：深渊难爬
    └─→ 结局B：理性救赎
    ↓
【升华】结幕：反诈提示
```

## 三、技术实现方案

### 3.1 数据结构设计

```python
# 剧情节点结构
{
    "role": "旁白/角色名/心理/系统/真相",  # 角色类型
    "content": "对话内容",                    # 显示文本
    "bg": "index/pg1/pg2/pg3",              # 背景图key
    "hidden_clue": "clue_x",                # 可选：隐藏线索
    "set_flag": "flag_name",                # 可选：设置标记
    "set_money": 1000,                      # 可选：累计损失金额
    "type": "choice/ending",                # 特殊类型
    "options": [                            # choice类型专用
        {"text": "...", "next": 26}
    ],
    "ending_id": "ending_a",                # ending类型专用
    "ending_name": "深渊难爬",
    "ending_type": "bad/good"
}
```

### 3.2 状态管理
```python
class AntiFraudGame:
    def __init__(self, root):
        # 剧情状态
        self.idx = 0                         # 当前节点索引
        self.script = load_script("gambling") # 赌局陷阱脚本
        
        # 游戏状态
        self.flags = set()                   # 选择标记集合
        self.clues_collected = []            # 收集的线索
        self.money_lost = 0                  # 累计损失金额
        self.current_ending = None           # 当前结局ID
```
