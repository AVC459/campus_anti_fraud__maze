# 《咸师反诈迷雾：赌局陷阱》角色设计文档

## 一、故事背景

本故事讲述咸师大三学生小夏，被同班同学老蛋以"轻松挣钱"为诱饵，陷入网络赌博诈骗陷阱，在同学小林的劝导下，最终做出正确选择的故事。

---

## 二、角色一：小夏

### 1. 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 小夏 |
| 性别 | 男 |
| 年龄 | 20-22岁 |
| 身份 | 咸师大学生（大三） |
| 特点 | 勤工俭学、家境普通 |

### 2. 外貌特征

| 项目 | 描述 |
|------|------|
| 身高 | 175-180cm（高挑） |
| 相貌 | 清秀帅气、眉目清朗、眼神清澈 |
| 发型 | 普通短发，清爽干净，刘海微微遮额 |
| 脸型 | 瓜子脸或清瘦的鹅蛋脸 |
| 肤色 | 正常肤色，略偏白（室内学习为主） |

### 3. 性格特点

- **善良正义**：面对小林的劝导能够听取并改正
- **踏实努力**：常年兼职，不怕辛苦
- **有侥幸心理**：面对"轻松挣钱"的诱惑会动摇
- **珍惜情谊**：感激小林的帮助和陪伴

### 4. 服装风格

- **日常穿着**：普通大学生休闲装
- **上衣**：白色/浅蓝色T恤或衬衫，干净整洁
- **下装**：浅色牛仔裤或休闲裤
- **鞋子**：普通运动鞋或帆布鞋
- **细节**：衣服可能有发传单的广告logo痕迹，体现兼职生活

### 5. 表情变化

| 场景 | 表情 |
|------|------|
| 兼职归来 | 疲惫但温和，眼神坚定 |
| 被诱惑时 | 期待、兴奋、眼神有光 |
| 小赢一笔 | 惊喜、兴奋、手舞足蹈 |
| 首次亏损 | 震惊、难以置信 |
| 越输越多 | 慌乱、慌张、手心出汗 |
| 听取劝导后 | 释然、感激、坚定 |

### 6. 场景造型

- **姿态**：站姿或坐姿，略显疲惫但努力支撑的感觉
- **手势**：有时紧张地握着手机
- **视线**：从期待→慌乱→迷茫→释然的情绪变化

### 7. 设计风格参考

- 二次元/插画风格
- 参考现有角色（路人甲、乙）的简洁线条风格
- 柔和的色彩搭配
- 人物占画面高度约42%

## 三、角色二：老蛋

### 1. 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 老蛋 |
| 性别 | 男 |
| 年龄 | 21-23岁 |
| 身份 | 小夏的同班同学 |
| 真实身份 | 诈骗团伙利用的"托儿" |

### 2. 外貌特征

| 项目 | 描述 |
|------|------|
| 身高 | 170-175cm（比小夏略矮） |
| 相貌 | 看起来比较精明，眼神有些飘忽 |
| 发型 | 稍显凌乱，刻意打理过但不整齐 |
| 脸型 | 圆润脸庞，略带油腻感 |
| 肤色 | 略暗沉 |

### 3. 性格特点（表面）

- 吊儿郎当
- 出手大方，经常请大家吃饭
- 热情友好，主动接近同学

### 4. 真实面目

- 被诈骗团伙收买
- 忽悠同学参与赌博
- **关键细节**：手会不自觉地抖动（暗示心虚紧张）

### 5. 服装风格

- **穿着**：比小夏更讲究，名牌或潮牌
- **上衣**：黑色或深色T恤，可能有logo
- **下装**：深色裤子
- **配饰**：可能戴手表或链子，刻意炫耀
- **整体感觉**：暴发户式的"有钱人"形象，有刻意炫耀的感觉

### 6. 表情变化

| 场景 | 表情 |
|------|------|
| 推荐"挣钱路子"时 | 笑容灿烂、过于热情、不自然 |
| 小夏赢钱时 | 兴奋过头、极力怂恿继续 |
| 小夏输钱时 | 假装安慰、继续撺掇、眼神飘忽 |
| 被揭穿时 | 慌张、想逃走、冷汗 |

### 7. 关键细节

- **手部特写**：手会不自觉地抖动，这是心虚的表现
- **眼神**：经常看向别处，不敢直视对方
- **手机**：经常拿着手机，屏幕上显示那个简陋的赌博APP

### 8. 场景造型

- **姿态**：勾肩搭背的亲密姿态，显得很"热情"
- **距离**：与目标人物距离过近，过于亲近
- **隐藏线索**：手的抖动、眼神的飘忽

### 9. 设计风格参考

- 二次元/插画风格
- 参考现有角色（路人甲、乙）的简洁线条风格
- 深色调为主，体现阴暗面
- 人物占画面高度约42%

## 四、技术规格

| 项目 | 规格 |

| 文件格式 | PNG（支持透明背景） |

## 六、创作提示

### 小夏的积极形象要点

1. **阳光正面**：整体形象要积极健康，体现大学生朝气
2. **勤奋感**：通过服装细节体现兼职生活
3. **情绪变化**：眼神从期待到慌乱再到释然的变化
4. **成长蜕变**：最终选择正确道路后的坚定眼神

### 老蛋的反派形象要点

1. **伪装友善**：表面热情但笑容不自然
2. **心虚细节**：手部抖动、眼神飘忽是关键
3. **阴暗气质**：整体色调偏暗，体现内心阴暗
4. **危险信号**：让观众感觉"哪里不对劲"
