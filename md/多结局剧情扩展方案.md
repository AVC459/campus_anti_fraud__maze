# 多结局剧情扩展方案

## 一、现状分析

**当前游戏结构**
- 类型：Python Tkinter 文字冒险游戏
- 主题：校园网恋诈骗防范
- 主角：大学新生，独自面对"林舒学姐"的网恋诈骗

**现有结局（仅2个）**
1. **梦碎深渊** - 转账给骗子 → 被拉黑 → 完全被骗
2. **理性的胜利** - 报警处理 → 识破骗局 → 钱财保住

**当前剧情分支点**
```
第一选择(第60-63行)：如何回应学姐的善意
  → 情感回应 → 跳到第17行继续
  → 理性回馈 → 跳到第17行继续

第二选择(第80-84行)：学姐"出事"后的紧急抉择
  → 倾其所有(转账) → 结局1：梦碎深渊
  → 理智底线(报警) → 结局2：理性的胜利
```

---

## 二、扩展方案

### 方案概述：增加 3 个新结局，形成 5 结局体系

| 结局 | 名称 | 触发条件 | 剧情特点 |
|------|------|----------|----------|
| 结局1 | 梦碎深渊 | 转账5000元 | 被完全诈骗，最坏结局 |
| 结局2 | 理性的胜利 | 报警处理 | 识破骗局，最好结局之一 |
| 结局3 | 暧昧陷阱 | 拒绝转账但继续联系 | 被多次借钱，少量损失 |
| 结局4 | 反诈先锋 | 提供线索协助破案 | 最好结局 + 获得荣誉 |
| 结局5 | 迷雾真相 | 发现学姐是卧底警察 | 隐藏结局，意外反转 |

### 具体剧情分支设计

#### 新增第一分支点（第60-63行处增加新选项）

```
原选项：
A.【情感回应】"学姐你对我太好了，等我面试过了，一定请你吃大餐！"
B.【理性回馈】"总是麻烦你真不好意思，我转红包给你吧。"

→ 新增选项：
C.【保持距离】"谢谢学姐，但我刚来学校还是想先专注适应，不太好意思收礼物"
```

#### 新增第三分支点（第80-84行的抉择前增加过渡剧情）

在最终抉择前，增加一个"中间选择"来区分结局3和结局4/5：

```
第二选择后的过渡(第78行后)：
  → 看到学姐哭泣后，系统弹出中间选择

【中间选择】"学姐你先别急，我能帮你做点什么？"
  A. "我给你转2000，先应个急" → 结局3：暧昧陷阱
  B. "我认识一个反诈社团的前辈，我帮你问问" → 触发结局4/5路线
```

#### 结局3详细设定：暧昧陷阱
- **触发**：选择转2000元"小钱"给学姐
- **剧情**：学姐继续联系，以各种理由借款（机票钱、手术费、培训费）
- **累计损失**：每次500-2000元，共3次，累计约5000元
- **最终发现**：学姐消失，发现被骗
- **结局展示**：Loss 显示累计金额，展示被骗过程

#### 结局4详细设定：反诈先锋
- **触发**：选择"找反诈社团前辈帮忙"
- **剧情**：
  - 联系反诈社团，发现这是典型"杀猪盘"案例
  - 在前辈指导下，假装继续配合，获取骗子更多信息
  - 配合警方，成功捣毁诈骗窝点
- **结局展示**：
  - 警察局表彰
  - "你协助破获了一起重大电信诈骗案"
  - 获得【反诈先锋】称号 + 奖金

#### 结局5详细设定：迷雾真相（隐藏结局）
- **触发条件**：
  - 在第一分支点选择"保持距离"
  - 在中间选择选择"找反诈社团前辈"
  - 并且在游戏过程中收集到3个隐藏线索（剧情中会提到）
- **隐藏线索位置**：
  1. 第48行：学姐说"南门台阶" - 真实校园没有这个地点
  2. 第54行：学姐的生日是2月30日（不存在）
  3. 第71行：候车厅声音嘈杂，但背景里有广播说"本次列车终点站：xxx"
- **剧情反转**：
  - 原来"林舒学姐"是卧底警察，一直在暗中调查诈骗集团
  - 她故意接近主角来测试他的防骗意识
  - 主角通过了测试，获得"反诈潜力股"称号
- **结局展示**：反转画面 + "你以为的骗局，其实是场考试"


### 2. 游戏状态管理扩展

```python
class AntiFraudGame:
    def __init__(self, root):
        # 新增状态
        self.flags = set()          # 标记集合
        self.clues_collected = []   # 收集的隐藏线索
        self.money_lost = 0         # 累计损失金额

        # 结局判定
        self.current_ending = None
```

### 3. 结局判定逻辑

```python
def check_ending(self):
    """在关键节点判定结局"""
    if self.money_lost >= 5000:
        return "dream_shatter"  # 结局1
    elif "reported" in self.flags and self.money_lost == 0:
        return "rational_victory"  # 结局2
    elif 0 < self.money_lost < 5000:
        return "ambiguous_trap"  # 结局3
    elif "helped_police" in self.flags:
        return "anti_fraud_hero"  # 结局4
    elif len(self.clues_collected) >= 3 and "keep_distance" in self.flags:
        return "truth_revealed"  # 结局5
```
