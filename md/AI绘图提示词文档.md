## 四、使用建议

### 推荐AI工具

| 工具 | 特点 | 推荐用途 |
|------|------|----------|
| **Midjourney** | 艺术感强，质量高 | 角色设计、场景背景 |
| **Stable Diffusion** | 可控性强，本地运行 | 批量生成、风格统一 |
| **DALL-E 3** | 理解力强，细节好 | 复杂场景、道具设计 |
| **通义万相** | 中文支持好 | 国内用户首选 |
| **文心一格** | 中文支持好 | 国内用户备选 |

### 生成参数建议

```
角色图片：
- 尺寸：512x768 或 768x1024（竖版）
- 步数：30-50
- CFG：7-9
- 采样器：DPM++ 2M Karras

背景图片：
- 尺寸：1920x1080（横版）
- 步数：40-60
- CFG：7-8
- 采样器：Euler a
```

### 后处理步骤

1. **角色图片**：
   - 使用 remove.bg 或 Photoshop 去除背景
   - 调整尺寸至统一高度
   - 保存为 PNG 格式

2. **背景图片**：
   - 调整至 1920x1080
   - 保存为 JPG 格式（质量85%）

### Stable Diffusion WebUI API 调用示例

import requests
import json

url = "http://127.0.0.1:7860/sdapi/v1/txt2img"

payload = {
    "prompt": "anime style illustration, 1boy, male college student...",
    "negative_prompt": "nsfw, nude, low quality...",
    "steps": 40,
    "width": 768,
    "height": 1024,
    "cfg_scale": 7.5,
    "sampler_name": "DPM++ 2M Karras"
}

response = requests.post(url, json=payload)
